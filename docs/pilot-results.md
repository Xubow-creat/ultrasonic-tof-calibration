# 稀疏校准约束的横向非均匀层 ToF 修正：首轮验证

本轮只解决一个问题：当表层声速沿横向变化时，两个已知反射体提供的 FMC 到达时间，能否估计用于未见缺陷定位的传播时间修正？这不是论文创新性或工程适用性的最终证明。

## 方法

- 正向数据：本地 k-Wave Python 的 C++/OMP 后端，二维标量声学仿真。8 阵元逐个发射、所有阵元接收，形成 `8×8×T` FMC。
- 材料：4.8 mm 深的表层，背景速度 4500 m/s；下层 5900 m/s。横向高斯慢速区的真实振幅为 −1200 m/s、中心为 1.6 mm、宽度为 1.8 mm。激励频率为 2.2 MHz。
- 校准数据：两个已知点状反射体，坐标为 (−1.8, 8.0) 和 (1.8, 10.0) mm。每个反射体单独仿真，并减去相同材料的无反射体参考 FMC，再拾取多通道到达时间。
- 待估参数：表层背景速度、横向慢速区振幅与中心、公共时间偏移。界面深度、下层速度、慢速区高斯形状和宽度在本实验中视为已知。用分层射线的费马最短传播时间进行拟合，随后用于 TFM。三个测试反射体均未参与拟合。
- 比较方法：名义恒定声速 TFM、校准后的全局声速与时间偏移、仅随深度变化的分层速度、横向变化的校准模型。所有方法在同一固定成像区域 `x∈[−3.6,3.6] mm, z∈[8.2,14.4] mm` 中找最大峰。

## 结果

校准模型得到表层背景速度 **4487.5 m/s**（真值 4500）、慢速区振幅 **−1178.6 m/s**（真值 −1200）、中心 **1.609 mm**（真值 1.6）。两个反射体各取 36 个上三角通道，共 72 个到达时间；加权拟合残差约 **0.00169 μs**。全局声速模型残差约 **0.112 μs**。

| 未参与校准的目标 (x,z) mm | 名义 TFM 定位误差 mm | 全局声速校准 mm | 深度分层校准 mm | 横向模型校准 mm |
| --- | ---: | ---: | ---: | ---: |
| (−1.0, 11.4) | 2.91 | 2.66 | 2.60 | <0.1 |
| (1.1, 11.4) | 3.33 | 2.62 | 2.40 | <0.1 |
| (2.5, 12.2) | 3.48 | 2.60 | 2.73 | <0.1 |

`<0.1 mm` 只表示在 **0.1 mm 成像网格**上最大峰恰好落在目标网格点，不能解释为已验证的实际定位精度。三个测试目标共享同一个材料场与同一组校准数据，因而不是三个独立试件。

控制实验表明：当表层横向均匀时，全局声速加公共时间偏移已将一个未见目标恢复到网格点；更复杂的分层模型无明显额外收益。只有引入横向变化后，本实验的简单全局校准才明显失效。

## 结论边界

这组结果支持继续研究“从少量校准回波估计具有物理约束的横向 ToF 场”，但**还不能声称发现了新的方法或解决了真实焊缝检测**。[Singh 等人 2022 年的焊缝研究](https://strathprints.strath.ac.uk/79101/)已用学习到的材料信息修正 TFM 延时；这里的低维参数拟合应视为基线和可行性验证。这里预先指定了正确的高斯慢速区形状与宽度，并使用了同材质无反射体参考信号做差；实验没有噪声、耦合变化、未知微结构或真实弹性模式转换。仅把假定的慢速区中心偏移 0.6 mm 时，模型背景速度拟合落到参数下界，提示材料参数可能对先验几何敏感。把宽度错设为 2.7 mm 时，测试目标的峰值仍在目标网格点，但估计的材料参数明显偏离真值，说明“成像位置正确”不能代替“参数识别正确”。

下一道验证关口应使用多组独立材料场、错误的几何先验、原始未做参考相减的 FMC、噪声和探头位置扰动；比较到达时间、定位与误报。通过后，再考虑弹性全波求解器和真实试件。神经算子在这个阶段还没有必要。

## 复现

主脚本：[tof_calibration_pilot.py](../tof_calibration_pilot.py)。本轮实验使用 Python 3.12、k-Wave Python 0.6.3rc1 与 Windows C++/OMP 二进制。安装依赖的方法见仓库首页。首个完整仿真命令：

```powershell
python .\tof_calibration_pilot.py --lens-delta -1200 --fit-lens-center --out outputs/tof_calibration_full_rerun
```

本轮各目标的 `pilot_data.npz` 和 `results.json` 保存在仓库的 [`examples/`](../examples/) 中；[成像比较图](../figures/comparison.png) 显示同一材料场中的三个未见目标。`examples/center/pilot_data.npz` 包含完整的参考 FMC、校准数据与该目标的 FMC。`examples/uniform` 保存横向均匀表层的控制实验，`examples/width_mismatch/results.json` 保存宽度先验失配的拟合结果。
